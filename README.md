## ✨ Features

- Choose a workout type
- Adjust sets, speed and break length
- Sound cue on each step

## 🚀 Getting Started

**Prerequisites:** [Node.js](https://nodejs.org/) 18 or newer

**Install and run**

```bash
git clone https://github.com/miladmo68/workout-timer.git
cd workout-timer
npm install
npm start
```
